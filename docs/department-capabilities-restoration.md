# 部门助手能力恢复（独立验收环境，2026-10-30）

本次恢复旧部门助手的业务工具，不修改现网 3080/3081、Nginx、生产数据或上游 Harness。沿用 dsh-v0.1.5-rc.1、统一登录、个人/公司隔离、四实例上限及空闲回收。

## 配置与权限

- 模式恢复名称“部门助手模式”和任务文件、流程、模板、交付物的业务说明。配置组成位于 `backend/app/features/assistant/department_preset.py`。
- 恢复原生 bash、文件读写/编辑/图片读取、文件名和正文搜索、skill、交互提问、todo、长对话压缩与结果裁剪。
- `/compact` 只允许无参数调用，经过当前会话授权版本检查；不开放 `/permission`、任意插件命令或预设修改。
- 原生 skill 的目录和正文通过已发布资源网关实时读取，不扫描旧共享目录。其他公司、草稿及停用技能不会进入部门技能目录。
- `department_skill_prepare` 需要当前空间的技能使用和源码查看权限，才能将已发布资源准备到个人工作区；限制 512 个资源、10 MiB，并先检查存储余量。只创建新的个人副本，既有文件和正式发布版本不覆盖。
- 只有技能使用权限的成员仍可用 `department_reimbursement_generate` 执行报销，不需要源码权限。其他技能如需直接执行源码，必须具备源码权限及对应运行依赖；不能借恢复 Shell 绕过源码保护。
- 报销继续用独立执行器运行已发布 Python 脚本和 Office 依赖。个人原生 Shell 保留 workspace-write 沙箱、原生审批、无网络容器、只读系统及独立 home；没有开放宿主 Shell、共享目录、外网软件安装或管理员密钥。
- 技能草稿可以在个人工作区编写；正式技能发布与修改继续走系统权限和审核。
- 模型服务沿用已接入的原生个人模型设置；不增加配置页面。
