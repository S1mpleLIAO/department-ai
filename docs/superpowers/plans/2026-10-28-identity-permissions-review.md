## 最终验证矩阵与执行方式

| 维度 | 必测场景 |
|---|---|
| 身份 | 未登录/正常/停用/过期/重置/退出其他设备 |
| 范围 | 中科信控、森远、共享、历史未分配；同用户双公司多标签页 |
| 权限 | 只读、创建、自有草稿、编辑他人、审核、直接发布、下架、技能使用/源码 |
| 内容 | 草稿、待审、退回、通过未发布、发布失败、已发布、已归档 |
| 通道 | 页面、REST、MCP、向量/关键词、下载/预览、WS/mux、shell/fs |
| 故障 | Cookie 到期、实例重启、网关故障、发布中断、重复请求、并发审核、资源耗尽 |

后续测试均在阿里云隔离测试库和工作区执行。现有 `backend/tests/*_check.py`、`frontend/tests/*_check.mjs` 与模块边界检查按改动范围复用；新增授权和审核测试针对实际服务行为，不只匹配源码文本。实机流程测试不得运行旧的 live CRUD 检查去修改生产业务数据。
